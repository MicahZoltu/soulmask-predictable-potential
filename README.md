# Predictable Potential

Predictable Potential is a Soulmask mod that makes tribesman advancement predictable instead of a matter of capture luck.

Every recruit of a class gets the same proficiency caps and a level-based starting skill, talents are assembled from the same readable slots, weapon masteries unlock reliably, and your roster grows gradually as your awareness rises.

Quality stays random on purpose, so it remains the one reason to keep looking for a better recruit.

## Proficiency caps

In the unmodded game a recruit's proficiency cap is rolled when it is generated (spawned), so two Warriors can end up with very different ceilings.

This mod fixes those rolls: a class skill now caps at 125 and every other skill caps at 85, for every recruit, regardless of level, quality, rank, region, or captured archetype.
These are the caps the recruit is generated with; a Training Ground can still raise an off-class skill above 85 toward its mentor's cap, which this mod leaves alone.

A class skill is any skill in the recruit's class set.

| Class | Class skills |
| --- | --- |
| Warrior | Spear, Blade, Shield, Bow, Dual-Blade, Gauntlets, Great Sword, Hammer, Whip |
| Hunter | Spear, Blade, Shield, Bow, Harvest, Logging |
| Guard | Spear, Blade, Shield, Bow, Great Sword, Mining |
| Laborer | Spear, Shield, Logging, Mining, Harvest, Plant |
| Porter | Gauntlets, Weaving, Potting, Wood & Stone, Leatherworking, Kiln |
| Craftsman | Gauntlets, Craftsman, Alchemy, Cooking, Weapon Crafting, Armor Crafting |

## Starting proficiency

Starting skill is now tied to the recruit's level rather than rolled randomly.

A non-class skill begins on a shared curve: 1 at level 1 and 76 at level 50.

A class skill begins 36 points higher on the same curve: 37 at level 1 and 112 at level 50.

Both lines stop just short of their cap, leaving a little room to train.

## Weapon mastery

Each weapon has mastery unlocks at proficiency 30, 60, 90, and 120.

Every threshold a recruit can reach now always grants an unlock on the first attempt instead of a coin flip, and the unlock is still a random pick from that threshold's pool that never repeats an ability the recruit already knows.

Class weapons cap at 125 and can reach all four thresholds; weapons outside the class cap at 85 and reach the first two.
Again these are the caps the recruit is generated with, and Training Ground training can still push a weapon above 85 toward its mentor's cap.

The extra mastery a recruit receives at proficiency 0 from its random starting weapons is generated by the game natively and stays random; it is the one recruit-starting mastery detail this mod does not control.

## Talents

Every recruit is now assembled from the same talent slots, so its build is readable at a glance.

- One Origin talent at the top tier, whose growth bonus matches the class skill set, with descriptions that name that skill set.
- One Battle-Tested talent at star III, which reduces damage taken while the recruit is deployed, now granted to every class rather than only the fighting classes.
- One tribal talent at star III, drawn from a small set for the recruit's tribe.
- One class talent drawn from a small set for the recruit's class, with its tier set by the recruit's quality.
- A few preferences, which are mood-only likes and aversions; the gear-bound preferences are removed, and the number drawn is still the game's own random 0-3.

Recruits no longer receive defects, and they no longer start with a title.

Quality sets the class talent's tier: red is tier III, yellow is tier II, and purple is tier I.

White, green, and blue recruits receive no class talent.

## Quality and rarity

Quality is deliberately left random, because it is what keeps a good recruit special.

It sets the class talent's tier and the recruit's starting gear, but it does not change caps or starting skill, so a white recruit and a red recruit of the same class share the same ceiling.

## Roster growth

Your personal tribesman limit starts at the same base of 3 and now grows in fifteen small steps, one every four awareness levels from awareness 4 to 60, instead of only at a few milestones.

In Survival each step adds 3, reaching a personal cap of 48; in Tribe Mode each step adds 6, reaching 93.

The world's tribe limit still applies, so both numbers hold only where your world allows: a restricted or dedicated group-1 world starts that limit at 40, and guild upgrades can raise a Survival roster the rest of the way but cannot carry a Tribe Mode roster to 93.

Action, Creative, and PVP are not covered and fall back to 1 per step.

## Good to know

These changes apply to tribesmen generated after the mod is installed; a recruit captured earlier keeps the caps, starting skill, talents, and archetype gifts it already has, so a fresh world is the cleanest way to see the full effect.

So far the base proficiency cap and the Survival roster ramp are the parts confirmed on a running game; the remaining changes are built from the game's own data and have not yet been checked against a fresh recruit.

The Tribe Mode side of the roster ramp is enabled but not yet confirmed in a live game.

If you continue an existing world that has already saved roster values, its saved settings can keep an older, lower limit, so a fresh world avoids the issue.
